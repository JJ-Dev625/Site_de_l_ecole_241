Site Web École 241 - Landing Page Institutionnelle

Description
Ce projet consiste en l'intégration d'une landing page moderne, organisée et responsive pour le site de l'École 241.
Réalisé à partir d'une maquette , ce site a pour but de présenter l'établissement, ses chiffres clés, ses différentes filières de formation ainsi que les projets phares réalisés par les apprenants.

Technologies Utilisées

HTML5: Structuration sémantique avancée (<header>, <main>, <section>, <article>, <footer>).
CSS3: Mise en page moderne, utilisation des variables CSS pour la cohérence graphique, et gestion des alignements avec *Flexbox*.
Git & GitHub: Versionnement du code et suivi du projet.

Fonctionnalités
Navigation Sémantique & Fluide : Un menu d'en-tête clair avec des effets de survol et un défilement fluide vers les sections de la page.
Section Hero: Une zone d'introduction percutante avec des appels à l'action (CTA) clairs pour inciter à postuler.
Compteur de Statistiques: Affichage des chiffres clés de l'impact de l'école.
Grille de Formations & Projets: Présentation épurée sous forme de cartes (cards) respectant scrupuleusement les espacements et les arrondis demandés.
Design Responsive: Interface entièrement adaptative pour offrir une expérience de navigation optimale sur ordinateurs, tablettes et smartphones.
